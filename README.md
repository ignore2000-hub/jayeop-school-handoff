# 자영업자학교 홈페이지 인수인계

공개 사이트: https://jaeyeop-school.ignore2000.chatgpt.site/

AI연구소에서 기존 홈페이지를 받아 최종 디자인과 동작을 점검합니다.

## 작업 파일

- 작업 폴더: 자영업자학교 사이트/publish-checkout
- 메인 페이지: dist/index.html
- 이미지와 로고: dist/assets/
- 정적 사이트 배포 설정: .openai/hosting.json
- 소스를 전달할 때 dist 폴더와 하위 파일을 함께 전달해야 합니다.

## 현재 반영된 내용

- 사진을 WebP로 바꿔 페이지 무게를 줄였습니다.
- 첫 화면 강의 사진은 흐림 없이 4초마다 바뀝니다. 오른쪽 위에 사진 일시정지 버튼이 있습니다.
- 화면 순서: 고민 점검 → 실제 사례 → 교육 내용 → 대표·강사진 → 실적 → 후기 → 맞는 사장님 → 자주 묻는 질문 → 문의
- 1분 점검: 업종과 고민을 고르고 질문 5개에 네 / 아니요 / 모르겠어요로 답하면, 먼저 손볼 것과 다음 단계(혼자 / 배워서 / 함께 고치기)를 보여 줍니다. 답변은 저장되거나 전송되지 않습니다.
- 온라인 채널 9개와 AI 도구 10개를 누르면 특징, 활용 예시, 해 보면 손에 남는 것, 사례가 나오는 창이 열립니다.
- 바로가기 페이지: `dist/links.html` (인스타그램·카톡 프로필용 링크 모음)
