# 자영업자학교 홈페이지 인수인계

공개 사이트: https://jaeyeop-school.ignore2000.chatgpt.site/

AI연구소에서 기존 홈페이지를 받아 최종 디자인과 동작을 점검합니다.

## 작업 파일

- 작업 폴더: 자영업자학교 사이트/publish-checkout
- 메인 페이지: dist/index.html
- 이미지와 로고: dist/assets/
- 정적 사이트 배포 설정: .openai/hosting.json
- 소스를 전달할 때 dist 폴더와 하위 파일을 함께 전달해야 합니다.

## 현재 반영된 내용

- 첫 화면 강의 사진 18장이 약 0.3초 간격으로 반복됩니다.
- 얼굴을 알아보기 어렵도록 배경에 흐림 효과를 넣었습니다. 원본에 적용한 익명화가 아니므로, 사진 파일 자체의 익명화가 필요하면 이미지도 별도로 처리해야 합니다.
- 첫 화면 오른쪽 위에 사진 일시정지 버튼이 있습니다.
- 온라인 채널과 AI 도구 영역은 아이콘이 자동으로 이동하고 가운데 아이콘이 커집니다. 디자인은 추가 검토 대상입니다.

## 마무리 점검

1. 데스크톱과 모바일에서 첫 화면 사진 구도, 전환 속도, 글자 가독성을 확인합니다.
2. 일시정지와 재생, 주요 링크, AI 도구 아이콘을 확인합니다.
3. 변경사항을 미리보기로 확인한 뒤 기존 사이트에 배포합니다.
